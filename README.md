# The Matrix

An interactive, Matrix-inspired web experience built as a frontend portfolio project. The site brings the film’s iconic digital atmosphere to life with animated code rain, cinematic styling, and focused pages for the film and its cast.

## Project highlights

- Custom animated Matrix-style rain effect rendered on canvas
- Three navigable views: home, film overview, and cast
- Dark visual design with green accents and responsive layouts
- Interactive connection button that updates the on-screen status

## Built with

React 18 · Vite · CSS

## Live-Demo: https://matrix-react-app.vercel.app/

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

To create and preview a production build:

```bash
npm run build
npm run preview
```
